Cryptographic Architecture

Zero-knowledge mathematical pipeline verified on the client.

1

CSPRNG Salt & IV Generation

16-byte random salt and 12-byte initialization vector generated per document via window.crypto.getRandomValues().

2

PBKDF2 Key Stretching (310,000 Rounds)

Derives an ephemeral 256-bit AES key using HMAC-SHA256. Slows down offline brute-force attempts.

3

AES-256-GCM Authenticated Decryption

Galois/Counter Mode guarantees confidentiality and data integrity. Invalid passwords immediately fail the 16-byte authentication tag.

4

In-Memory DOM Reconstitution

Decrypted HTML is rendered strictly in volatile RAM. 0 bytes are written to disk or sent across the network.
