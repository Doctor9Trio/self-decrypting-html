Cryptographic Architecture

Zero-knowledge mathematical pipeline verified natively on the client.

1

CSPRNG Salt & IV Generation

16-byte random salt and 12-byte initialization vector generated per document via window.crypto.getRandomValues(). No IV or salt is ever reused.

2

PBKDF2 Key Stretching (310,000 Rounds)

Derives an ephemeral 256-bit AES key using HMAC-SHA256. Exceeds OWASP guidelines to prevent GPU/ASIC rainbow table and brute-force attacks.

3

AES-256-GCM Authenticated Encryption

Galois/Counter Mode guarantees both confidentiality and ciphertext integrity. Invalid passwords immediately fail the 16-byte authentication tag.

4

In-Memory Volatile DOM Reconstitution

Decrypted HTML is rendered strictly in volatile memory. 0 bytes are written to disk, and no data packets traverse the network.
